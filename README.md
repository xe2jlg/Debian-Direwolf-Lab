En este espacio se documentará el proceso de instalación de Direwolf 1.8 en una MacBook Air corriendo Debian.

Empezaremos con el proceso de instalación de la versión más reciente de Debian LTS para posteriormente instalar la versión 1.8 de Direwolf, que aún no está liberada en este momento, la razón de instalar una versión no liberada de Direwolf es que necesito una funcionalidad que apareció en 1.8 relativa a la posibilidad de usar múltiples instancias de la abstracción conocida como CHANNELS para un digipeater crossband de aprs.

La interfaz de audio que se usará es una DigiRig Lite, el radio que se usará en las pruebas es un ALinco DR-735, todos los cables y el adaptador USB C a USB A son cables marca DigiRig

La Macbook Air es early 2015 con 4 GB de RAM
